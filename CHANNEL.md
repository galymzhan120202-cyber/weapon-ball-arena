## Images

Rendered by `record/branding-shot.js` from `branding.html` (Apple-style treatment:
black stage, one chrome hero object, one accent, tight wordmark). Committed at the
repo root so they never have to be regenerated by hand:

| File | Size | Where it goes |
|------|------|----------------|
| `branding_banner.png` | 2560 × 1440 | Customisation → Branding → **Banner image** |
| `branding_avatar.png` | 800 × 800   | Customisation → Branding → **Picture** |

Regenerate (e.g. to reroll the accent or try the light treatment):

```
node record/branding-shot.js                 # default: Apple blue on black
node record/branding-shot.js --seed=5         # reroll the accent colour
# light treatment: open branding.html?theme=light and use the download buttons
```

The banner keeps all text inside the 1546 × 423 TV-safe area; the wordmark lockup
is centred, so it also sits centred on desktop/tablet crops.

## Settings checklist

- **Upload defaults** (Settings → Upload defaults): category **Gaming**, "not made
  for kids", visibility left at whatever the first manual test upload uses — the
  automated uploader sets everything per-video from `upload/meta.js` anyway.
- **Shorts:** no separate setting; vertical 1080×1920 clips are detected as Shorts.
- **Branding watermark:** optional — `branding_avatar.png` also works as the
  video watermark (Customisation → Branding → Video watermark).

## Still manual (PLAN.md §9)

1. Upload `branding_banner.png` + `branding_avatar.png`, paste the description +
   keywords above.
2. OAuth: new Desktop client in GCP `youtube-automation-489306` → `client_secrets.json`
   → `node upload/login.js` → `youtube_token.json`.
3. Repo secrets `WBA_CLIENT_SECRETS_JSON` / `WBA_YOUTUBE_TOKEN_JSON`.
4. Decide hosting, set `PLAY_URL` here and in `upload/meta.js`.
5. `director.yml` dry-run → one manual unlisted upload → let cron run.
